## 🚀 Вариант 1. Запуск с использованием Docker Compose (Рекомендуемый)

Этот способ автоматически разворачивает базу данных, применяет необходимые миграции (только если они действительно необходимы), наполняет БД сидами и запускает приложение.

### Требования
* Установленный **Docker** и **Docker Compose**

### Инструкция по запуску:
1. Создайте файл конфигурации окружения `.env` в корне проекта на .env.sample. Данные в нём уже актуальны для запуска через Docker, так что изменений не требуется.
2. Запустите сборку и старт всех контейнеров:
   ```bash
   docker compose up -d --build
   ```
3. Приложение станет доступно по адресу: [http://localhost:8000](http://localhost:8000)
4. Интерактивная документация API (Swagger): [http://localhost:8000/docs](http://localhost:8000/docs)

### Полезные команды для Docker:
* **Просмотр логов приложения:** `docker compose logs -f app`
* **Остановка проекта:** `docker compose down`

## 🛠️ Вариант 2. Локальный запуск (Без Docker Compose)

Этот способ подходит для разработки, отладки кода в IDE и запуска тестов напрямую на хост-машине.

### Требования
* Установленный **Python 3.12+**
* Пакетный менеджер **uv** (`pip install uv`)
* Запущенный локально сервер **PostgreSQL**

### Инструкция по запуску:

1. **Настройка окружения:**
   Убедитесь, что в вашем файле `.env` указана корректная строка подключения к вашей локальной базе данных PostgreSQL, например:
   ```env
   POSTGRES_USER=postgres
   POSTGRES_PASSWORD=postgres
   POSTGRES_DB=paygate_service
   DATABASE_URL=postgresql+asyncpg://postgres:postgres@localhost:5432/paygate_service
   ```

2. **Установка зависимостей:**
   Создайте виртуальное окружение и установите пакеты одной командой:
   ```bash
   uv sync
   ```

3. **Применение миграций:**
   Обновите структуру локальной базы данных до актуального состояния через Alembic:
   ```bash
   uv run alembic upgrade head
   ```

4. **Наполнение базы данных (Сидирование):**
   Создайте дефолтных пользователей и администратора в БД:
   ```bash
   uv run python -m src.db.seed_data
   ```

5. **Запуск сервера разработки:**
   Запустите FastAPI приложение с помощью Uvicorn:
   ```bash
   uv run uvicorn main:app --host 0.0.0.0 --port 8000 --reload
   ```
   Сервис будет доступен по адресу: [http://localhost:8000](http://localhost:8000)
